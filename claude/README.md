# Cat Facts App

A simple GUI application that displays random cat facts when you click on the cat nose image.

## Requirements

- Python 3.6+
- Required packages:
  - tkinter (usually comes with Python)
  - Pillow (PIL)
  - requests

## Installation

1. Install the required packages:

```
pip install pillow requests
```

## How to Run

1. Navigate to the app directory
2. Run the Python script:

```
python cat_facts_app.py
```

## How to Use

1. Launch the application
2. Click on the cat nose image to get a random cat fact
3. A new fact will be displayed in the text area each time you click the image
